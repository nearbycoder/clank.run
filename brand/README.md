# Clank brand mark

The Clank mark is a geometric clamp/C surrounding a live signal node. It uses the same restrained
palette as the framework and deployment platform:

- near black: `#090909`
- warm white: `#f0f0ed`
- signal green: `#9bef6b`

Use `clank-mark-512.png` for large raster placements, `clank-mark-64.png` or
`clank-mark-32.png` for compact UI, `apple-touch-icon.png` for home-screen metadata, and
`favicon.ico` for browser compatibility. Keep the square artwork intact; do not crop into the
symbol's safe area or recolor individual pieces.

The source concept was generated for Clank and then reduced to the exact three-color palette so
the geometry remains crisp at favicon sizes.
